# Abstract — Pitch Insight: AI-Driven Cricket Pitch Intelligence from Visual and Environmental Signals

Pitch assessment in cricket is still largely subjective, creating uncertainty in toss decisions, team selection, and in-match strategy. This work presents **Pitch Insight**, an end-to-end AI platform that converts a single pitch image into actionable strategy recommendations by combining deep learning, classical computer vision, and domain-informed post-processing. The system first detects the playable pitch region using a YOLOv8 ONNX model, then extracts interpretable surface descriptors (grass coverage, crack intensity, moisture proxy, color profile, texture, and brightness) using OpenCV pipelines. A second ONNX classifier (ResNet18/EfficientNet family) predicts four pitch behavior classes: batting-friendly, bowling-friendly, seam-friendly, and spin-friendly. To improve practical reliability, model probabilities are adjusted through transparent cricket heuristics and optionally refined with live weather context. The deployed stack uses a FastAPI backend, React frontend, MongoDB persistence, and subscription-aware features for professional workflows. Internal benchmarking indicates end-to-end inference latency of approximately **250–500 ms/image**, YOLO detection performance of **mAP@0.5 = 92.5%**, and baseline four-class classification accuracy of **78.5%**, with rule-based calibration improving effective field-level decision alignment to approximately **85% (estimated)**. The results suggest that hybrid AI pipelines—combining learned models with explainable feature rules—can deliver practical, low-latency decision support for cricket operations.
